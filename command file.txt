Run everything from:  E:\Micro\ArUcoMarkerDetector   (PowerShell)
Python is the project venv, so no activation is needed: .venv\Scripts\python.exe

-----------------
cd E:\Micro\ArUcoMarkerDetector

EXPECTED STATE ORDER (success)
------------------------------
SEARCH_PRODUCT -> DETECT_PRODUCT -> VERIFY_PRODUCT -> PICK_PRODUCT -> GET_TARGET_SHELF
-> NAVIGATE_TO_SHELF -> DETECT_SHELF -> ALIGN_WITH_SHELF -> APPROACH_SHELF
-> MOVE_TO_PLACEMENT_POSITION -> PLACE_PRODUCT -> VERIFY_PLACEMENT -> DONE

APPROACH_SHELF measures the camera-to-shelf-marker distance every frame and will not finish
until it reads <= standoff_cm + approach_tolerance_cm (40 cm by default). On a live webcam YOU
close that gap by walking the camera in; it prints "move NN cm CLOSER" while it waits.

Webcam window: press q or Esc in the preview window to abort (exit code 130).
Exit codes: 0 success, 1 run failed, 2 bad input/config, 3 camera error.
